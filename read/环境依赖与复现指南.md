# 环境依赖与复现指南

本文说明在本仓库中**复现 MuJoCo 仿真、Python IK/规划、ROS2 桥接、以及（可选）真机控制器编译与运行**所需的软硬件环境与依赖库。  
更偏「目录与脚本地图」的交接说明见 [PROJECT_HANDOVER_README.md](./PROJECT_HANDOVER_README.md)；仿真包内用法见 [../lens_dual_arm_description/README.md](../lens_dual_arm_description/README.md)。

---

## 1. 复现场景划分（按需准备）

| 场景 | 需要的环境概要 |
|------|----------------|
| **A. 仅 MuJoCo 仿真 + FK/IK/规划 GUI** | Python 3 + venv、**`requirements.lock.txt`（推荐）**或 `requirements.txt`、`python3-tk`、桌面 OpenGL（或兼容的 Mesa） |
| **B. A + ROS2 话题桥接**（`/joint_command`） | 在 A 基础上增加 **ROS2 发行版**；**同一 Python 解释器**需能 `import mujoco` 与 `import rclpy` |
| **C. Path IR HTTP 服务**（`llm_demo/fastapi_path_ir_sim_server.py`） | 锁定文件已含 **fastapi / uvicorn**；若仅用最小 `requirements.txt` 则需自行 `pip install fastapi uvicorn` |
| **D. ROS2 工作区 `lens_dual_arm`（C++ 控制器）** | Ubuntu + `build-essential`、`cmake`、`colcon`、ROS2 与 `package.xml` 中列出的依赖；EtherCAT 真机另需厂商 SDK 与 root/权限策略 |

下文按 **操作系统 → Python → 系统包 → ROS → C++/厂商 → 环境变量与自检** 顺序展开。

---

## 2. 操作系统与硬件

| 项 | 建议 |
|----|------|
| **操作系统** | **Ubuntu 22.04**（ROS2 Humble）或 **Ubuntu 24.04**（ROS2 Jazzy）。仓库内 Docker 与部分文档以 **Jazzy** 为例；若你使用 Humble，请将命令中的 `jazzy` 换成 `humble`。 |
| **架构** | x86_64 为主；`actuator_controller_aarch64/` 供 ARM 真机侧编译参考。 |
| **显示** | MuJoCo 自带 `mujoco.viewer` 需要 **OpenGL**；无显示器服务器可用 OSMesa/虚拟显示（未在本仓库内单独封装，需自行按 MuJoCo 文档配置）。 |
| **内存 / 磁盘** | 仿真与 colcon 构建建议 ≥8 GB 内存；预留数 GB 给 `build/`、`install/` 与 venv。 |

## 4. pip 依赖（仿真包 `lens_dual_arm_description/`）

### 4.0 一键锁定安装（无绝对路径）

在**仓库根目录**（能看到 `lens_dual_arm_description/` 与 `scripts/`）执行其一即可。

**方式 A：脚本（推荐）**

```bash
bash scripts/bootstrap_python_venv.sh
source .venv/bin/activate
```

**方式 B：单条命令（复制粘贴）**

```bash
test -f lens_dual_arm_description/requirements.lock.txt && python3 -m venv .venv && .venv/bin/python -m pip install -U "pip>=25.1" "setuptools>=75.0" "wheel>=0.45.0" && .venv/bin/python -m pip install -r lens_dual_arm_description/requirements.lock.txt && .venv/bin/python -c "import numpy, mujoco, fastapi; print('OK')"
```

锁定文件路径：`lens_dual_arm_description/requirements.lock.txt`（含 **numpy / mujoco** 及 **FastAPI 栈** 的全量固定版本，便于团队一致复现）。

### 4.1 最小集合（`requirements.txt`）

文件路径：`lens_dual_arm_description/requirements.txt`。

| 包 | 版本约束（文件内） | 用途 |
|----|-------------------|------|
| **numpy** | `>=1.24` | 数组与数值计算 |
| **mujoco** | `>=3.0.0` | 模型加载、前向运动学、雅可比、`mj_geomDistance`、viewer |

安装示例（在**仓库根目录**或任意目录均可，建议 venv 建在仓库根）：

```bash
cd /path/to/lens_dual_arm_description   # 仓库根：含 lens_dual_arm_description/ 子目录
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip setuptools wheel
pip install -r lens_dual_arm_description/requirements.txt
python -c "import numpy, mujoco; print('numpy', numpy.__version__, 'mujoco', mujoco.__version__)"
```

### 4.2 可选 pip（按脚本）

| 包 | 用途 | 安装 |
|----|------|------|
| **fastapi**、**uvicorn** | `llm_demo/fastapi_path_ir_sim_server.py` HTTP 服务 | `pip install fastapi uvicorn` |

> 其余 `llm_demo` 脚本主要依赖 **标准库** + 上述 `numpy`/`mujoco`；`text_to_path_ir.py` 若调用云端 API 需自行配置密钥与 `urllib` 环境。

## 5. 系统级依赖（apt 示例）

以下为 **Debian/Ubuntu** 常见包名；其它发行版请用等价包名。

### 5.1 仿真与 GUI 必备

| 包 / 组件 | 用途 |
|-----------|------|
| **python3-tk** | `tkinter`：所有 IK/规划滑条界面；缺失时报 `ModuleNotFoundError: No module named 'tkinter'` |

```bash

```

### 5.2 编译 ROS2 工作区（`lens_dual_arm`）

| 包 | 用途 |
|----|------|
| **build-essential** | gcc/g++/make |
| **cmake** | CMake ≥3.8（`lens_dual_arm_description/CMakeLists.txt` 要求 3.8+） |
| **git** | 获取依赖、colcon 常用 |
| **python3-colcon-common-extensions**（或元包） | `colcon build` |

```bash
sudo apt install -y build-essential cmake git python3-colcon-common-extensions
```

### 5.3 现场「MoveIt + 控制器」脚本（`lens_dual_arm/README.md`）

若使用文档中列出的 **Humble** 系列 MoveIt / ros2_control 包，需按该 README 逐条 `apt install`（发行版名与 `$ROS_DISTRO` 需与系统一致）。**未安装 MoveIt 仍可编译 `joint_controller_node`**，但无法运行依赖 MoveIt 的启动脚本。

## 6. ROS 2 依赖

### 6.1 发行版选择

- 与 **Ubuntu 24.04** 配套：**ROS 2 Jazzy**（本仓库 `docker/ethercat-build/Dockerfile`、部分 README 示例使用 `jazzy`）。
- 与 **Ubuntu 22.04** 配套：**ROS 2 Humble**（`lens_dual_arm/README.md` 中 MoveIt 安装示例为 `ros-humble-*`）。

安装步骤可参考官方或社区镜像文档（例如 [fishros ROS2 安装说明](http://fishros.org/doc/ros2/humble/Installation/Ubuntu-Install-Debians.html)，将 distro 换成你的版本）。

### 6.2 仿真侧 Python：`rclpy` 与 `mujoco` 并存

开启 `LENS_ROS_BRIDGE=1` 的脚本会 `import rclpy`。常见问题是 **venv 里只有 mujoco 没有 rclpy**，或 **ROS 自带环境没有 mujoco**。

**推荐做法（任选其一）：**

1. **venv + system site packages**（在已安装 `python3-rclpy` 或 ROS 自带 Python 的前提下）  
   ```bash
   python3 -m venv --system-site-packages .venv
   source /opt/ros/jazzy/setup.bash   # 或 humble
   source .venv/bin/activate
   pip install -r lens_dual_arm_description/requirements.txt
   python -c "import mujoco, rclpy; print('OK')"
   ```

2. **同一解释器内 pip 安装与 ROS 兼容的 rclpy**（较少用，取决于 ROS 与 pip 的 ABI 兼容性；优先用方案 1）。

每开新终端跑桥接脚本前：

```bash
source /opt/ros/<distro>/setup.bash
source /path/to/.venv/bin/activate
export PYTHONPATH=/path/to/repo/lens_dual_arm_description   # 从仓库根跑脚本时，使包内 import 生效
```

### 6.3 ROS2 工作区 `lens_dual_arm` 包级依赖（`package.xml`）

**`robot_interface`（消息/服务生成）**

- `ament_cmake`
- `rosidl_default_generators`
- `std_msgs`、`geometry_msgs`、`sensor_msgs`

**`joint_controller_node`**

- `ament_cmake`
- `rclcpp`
- `sensor_msgs`、`std_msgs`
- `robot_interface`（工作区内包）

使用 `rosdep` 安装缺失依赖（在 `lens_dual_arm` 目录下）：

```bash
source /opt/ros/<distro>/setup.bash
cd lens_dual_arm
rosdep update
rosdep install --from-paths src --ignore-src -r -y
```

### 6.4 运行时与中间件

| 项 | 说明 |
|----|------|
| **ROS_DOMAIN_ID** | 发布端与订阅端必须一致 |
| **RMW_IMPLEMENTATION** | 跨机或 `sudo` 时若发现话题不通，可尝试统一为 `rmw_cyclonedds_cpp`（以现场策略为准） |

## 7. C++ 控制器与厂商库（场景 D）

| 项 | 说明 |
|----|------|
| **CMake** | ≥3.8；控制器工程以 colcon/ament 为准 |
| **编译器** | 支持 C++17 的 GCC/Clang（以 `CMakeLists.txt` 为准） |
| **actuator_SDK** | 仓库内 `actuator_SDK_X86/`、`actuator_controller_aarch64/` 提供静态库与头文件；`ethercat_control.yaml` 中路径需指向本机实际位置 |
| **fmt / spdlog** | 与预编译 `libactuator_controller.a` **ABI 一致** 的版本；不匹配时用 `lens_dual_arm/docker/ethercat-build/` 内脚本在固定环境中构建（Dockerfile 内为 **fmt 8.1.x**、**spdlog 与 external fmt** 组合，以镜像内注释为准） |
| **LD_LIBRARY_PATH** | 若链接了非系统路径的 `libfmt.so` 等，运行期需包含对应 `lib` 目录（见 `lens_dual_arm/README.md`） |

## 10. 常见问题与依赖关系

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `No module named 'mujoco'` | 未在**当前** venv 安装 | `pip install -r lens_dual_arm_description/requirements.txt` |
| `No module named 'tkinter'` | 系统未装 tk | `sudo apt install python3-tk` |
| `No module named 'rclpy'` | 未 source ROS；或 venv 隔离了系统包 | `source /opt/ros/.../setup.bash`；或使用 `--system-site-packages` |
| `ModuleNotFoundError: left_arm_ik_slider` | 工作目录/`PYTHONPATH` 不对 | 从 `lens_dual_arm_description` 子目录运行，或设置 `PYTHONPATH` 指向该目录 |
| `Missing FastAPI deps` | 未装 HTTP 栈 | `pip install fastapi uvicorn` |
| 控制器链接 fmt 符号错误 | SDK 与系统 fmt 版本不一致 | 使用 `docker/ethercat-build` 隔离编译或对齐 `LD_LIBRARY_PATH` |

## 11. 依赖版本锁定建议（团队复现）

pip 侧可将当前环境导出为锁定文件，减少「同事机器上版本漂移」：

```bash
pip freeze > my-local-freeze.txt
```

将个人机器上的 `my-local-freeze.txt` 纳入版本管理前请**脱敏**（去掉本机路径）；或仅在内部 Wiki 附件中分发。仓库内维护的固定版本见 **`lens_dual_arm_description/requirements.lock.txt`**。  
ROS 侧以 **Ubuntu + ROS 发行版** 为基线锁定即可；C++ 以 Docker 镜像内 CMake/编译器版本为准。
