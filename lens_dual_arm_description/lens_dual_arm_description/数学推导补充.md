# 运动学数学推导补充（面向本项目）

本文是 `项目入门_URDF_FK_IK_奇异点.md` 的数学版补充，强调“公式 -> 数值算法 -> 代码实现”的映射。

---

## 1. 符号约定

- 关节向量：`q in R^n`，本项目左臂 `n = 7`
- 末端位置：`x(q) in R^3`
- 末端姿态：`R(q) in SO(3)` 或四元数 `quat(q)`
- 目标位置：`x_d`
- 位置误差：`e = x_d - x(q)`
- 雅可比：`J(q) = ∂x/∂q in R^(3xn)`

本项目 `left_arm_ik_slider.py` 是位置 IK，因此核心是 `3x7` 的位置雅可比 `J`。

---

## 2. FK：从关节空间到任务空间

## 2.1 齐次变换链

对于串联机械臂：

`T_0n(q) = T_01(q1) T_12(q2) ... T_(n-1)n(qn)`

末端位置和姿态可由 `T_0n` 读出：

- `x(q)` 是平移分量
- `R(q)` 是旋转分量

如果你采用 DH、POE 或直接按 URDF joint origin/axis 递推，本质都在构建 `T_0n(q)`。

## 2.2 本项目的 FK 校验逻辑

你在 `user_fk.py` 输出 `(pos, quat)`，与 MuJoCo 的：

- `data.xpos[ee_id]`
- `data.xquat[ee_id]`

做误差比较。这个过程等价于“你的解析 FK 与数值仿真 FK 对表”。

---

## 3. IK 线性化：为什么会出现雅可比

在当前迭代点 `q_k` 附近做一阶近似：

`x(q_k + dq) ≈ x(q_k) + J(q_k) dq`

希望 `x(q_k + dq)` 接近 `x_d`，得到：

`J dq ≈ e`

这就是每轮迭代要解的线性子问题。

---

## 4. 最小二乘与伪逆

若只做普通最小二乘：

`min_dq ||J dq - e||^2`

当 `J` 满秩时，最小范数解为：

`dq = J^+ e`

其中 `J^+` 是 Moore-Penrose 伪逆。  
问题在于：接近奇异时，`J^+` 对噪声和误差非常敏感，容易数值爆炸。

---

## 5. DLS（阻尼最小二乘）推导

## 5.1 优化目标

DLS 可写成：

`min_dq ||J dq - e||^2 + lambda^2 ||dq||^2`

这是 Tikhonov 正则化，抑制过大关节增量。

## 5.2 闭式解

对目标函数求导并令零，可得：

`dq = (J^T J + lambda^2 I)^(-1) J^T e`

在任务维小于关节维（本项目 `3 < 7`）时，常用等价形式：

`dq = J^T (J J^T + lambda^2 I)^(-1) e`

代码里采用的就是这一形式，计算更稳定且矩阵维度更小（`3x3`）。

---

## 6. 奇异点数学判据与工程含义

## 6.1 奇异值分解视角

对 `J` 做 SVD：

`J = U Sigma V^T`

`Sigma` 的最小奇异值 `sigma_min -> 0` 时，系统接近奇异。  
直觉上：末端某些方向“几乎不可动”。

## 6.2 条件数

`cond(J) = sigma_max / sigma_min`

- `cond` 小：数值条件好
- `cond` 大：误差放大明显，解不稳定

本项目打印 `Cond(J)`，用于在线观测。

## 6.3 可操作度（manipulability）

常用指标（位置任务）：

`w = sqrt(det(J J^T))`

`w` 越小，越接近奇异。  
项目中用 `w` 来做自适应阻尼调节。

---

## 7. 自适应阻尼：为什么有效

项目采用形式：

`lambda = lambda0 + k / (w + eps)`

并限制到 `[lambda_min, lambda_max]` 区间。  
效果是：

- 正常区：`w` 大，`lambda` 小，收敛快；
- 奇异区：`w` 小，`lambda` 大，抑制抖动和发散。

这是一种非常实用的“按工况调参”策略。

---

## 8. 步长限制与投影约束

迭代更新：

`q_(k+1) = clamp(q_k + dq, q_min, q_max)`

并对 `dq` 分量限幅（`step_clip`）。  
数学上它不是最优控制解，但工程上对实时系统非常关键：

- 避免单帧突变；
- 避免在关节边界附近来回震荡；
- 降低模型误差和离散时间带来的不稳定。

---

## 9. 冗余与零空间：主任务不变下做次任务

## 9.1 零空间投影矩阵

设（阻尼）伪逆近似为 `J^+`，则：

`N = I - J^+ J`

满足 `J N ≈ 0`，即 `N z` 基本不影响主任务误差一阶近似。

## 9.2 合成控制律

`dq = dq_task + dq_null`

其中：

- `dq_task = J^+ e`（或 DLS 版本）
- `dq_null = alpha * N * grad_h(q)`

`h(q)` 是次任务目标。本项目可理解为“离关节中值更近”，用 `bias` 近似梯度方向。

结果：末端仍跟踪目标，同时姿态分支更平滑、离限位更远。

---

## 10. 多解：从数学到实现

## 10.1 为什么会多解

对 7DoF 做 3D 位置任务，线性化方程：

`J dq = e`

欠定（unknown 7 > eq 3），其解空间可写作：

`dq = J^+ e + N z`

其中 `z` 任意，这就是多解来源（加上非线性全局分支会更多）。

## 10.2 本项目的实用求解范式

项目没有直接优化连续函数 `z`，而是采用“多初值 + 局部迭代 + 代价筛选”：

1. 构造多个初值（上一帧、关节中值、肘部偏置分支）；
2. 每个初值各跑一次 DLS；
3. 用代价函数选最优。

代价一般形如：

`cost = w1 * residual + w2 * smooth + w3 * limit_penalty`

对应需求：

- residual：任务精度
- smooth：时间连续性
- limit_penalty：远离边界

这比“单次伪逆直接出解”稳定很多。

## 11. 姿态误差（供你扩展到 6D IK）

当前项目主回路是位置 IK。若升级到位姿 IK，需要旋转误差项。  
一种常用形式（轴角近似）：

- `e_pos = x_d - x`
- `e_rot = 0.5 * vee(R_d R^T - R R_d^T)`（小角度近似）

堆叠任务误差：

`e_6d = [e_pos; e_rot] in R^6`

对应雅可比：

`J_6d = [J_pos; J_rot] in R^(6xn)`

然后同样可用 DLS：

`dq = J_6d^T (J_6d J_6d^T + lambda^2 I)^(-1) e_6d`

注意位置和姿态量纲不同，通常要加权矩阵 `W`。

## 12. 与项目参数的直接对应（便于调参）

`left_arm_ik_slider.py` 中主要参数：

- `max_iters`：每帧最大迭代次数（大了更准，小了更快）
- `pos_tol`：收敛阈值（越小越精确，但可能更慢）
- `step_clip`：每次迭代关节增量上限（稳定器）
- `base_damping`：基础阻尼（常态稳定性）
- `singular_damping_gain`：奇异区附加阻尼强度
- `nullspace_gain`：零空间次任务权重（限位回中强度）

建议调参原则：

1. 先保证“不会抖、不会跳、不会发散”；
2. 再追求“误差更小、响应更快”；
3. 任何调参都记录在 README，避免不可复现。
